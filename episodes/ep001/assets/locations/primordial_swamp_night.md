# 场景卡：原始沼泽（暴雨夜）

## 场景 ID

`primordial_swamp_night`

## 空间结构

- 开阔的低洼沼泽地，四周有低矮灌木和扭曲的古树
- 中心区域有一个发光漩涡/撞击坑（银蓝色光芒）
- 远处有岩石山崖（女娲出场位置）
- 地面为泥泞湿地，浅水覆盖

## 光线类型

- **主光源**：闪电（间歇性强光）
- **环境光**：极暗，深蓝灰色调
- **特殊光源**：撞击坑的银蓝色辐射光；觉醒后伏羲自身的金色光
- **整体感觉**：暴风雨中的戏剧性光线，明暗对比强烈

## 主色调

| 层次 | 色调 |
|------|------|
| 天空 | 深灰/墨蓝，乌云密布 |
| 地面 | 深褐/墨绿，泥泞反光 |
| 水面 | 暗灰蓝，反射闪电 |
| 特殊光 | 银蓝色（撞击坑）→ 暗金色（觉醒后） |

## 天气

暴雨倾盆，持续闪电，强风

## 镜头适配

| 景别 | 构图建议 |
|------|----------|
| 远景 | 沼泽全貌 + 天空占 2/3，人物极小 |
| 全景 | 沼泽地 + 发光漩涡 + 人物，展示空间关系 |
| 中景 | 人物 + 周围沼泽环境，水面反光 |
| 近景/特写 | 虚化背景为暗色 + 银蓝/金色光斑 |
