# 场景卡：灵子文明首都 · 数据中枢

## 场景 ID

`lingzi_civilization_capital`

## 空间结构

- 极致璀璨的未来都市
- 建筑由纯光构成（非实体材料）
- 数据河流在空中流淌（建筑之间）
- 中枢塔：城市最高点，羲和所在位置
- 控制台：塔顶的全息操控界面

## 光线类型

- **常态**：建筑自发光，柔和璀璨，暖白/金色
- **毁灭时**：光芒开始抽搐闪烁，加入红色警报光
- **火种启动后**：中心通天光柱（极亮白/金），其余逐渐暗去

## 主色调

| 状态 | 色调 |
|------|------|
| 正常（仅一瞬） | 暖白、金色、淡蓝 |
| 警报中 | 闪烁红 + 抽搐白 |
| 火种发射 | 极亮白金 → 亿万光点 |

## 镜头适配

| 景别 | 构图建议 |
|------|----------|
| 远景/广角 | 展示城市全貌：光构建筑 + 数据河流 + 天际线 |
| 中景 | 羲和在塔顶 + 背景城市 |
| 近景 | 羲和面部 + 全息数据反光 |
| 特效镜头 | 光柱从城市中心升起，占满竖屏纵向 |

## 使用范围

仅用于第一集场次 1-1。后续可能在闪回中复用。

## Prompt 前缀

```
breathtaking futuristic city built entirely of light, luminous crystalline architecture, rivers of golden-white data flowing through sky between buildings, central tower reaching highest point, holographic interfaces, advanced civilization at peak technology, warm golden-white illumination, cinematic sci-fi
```

```
all light glitching and stuttering, red alarm flashes, data streams fragmenting, city-wide emergency, buildings flickering
```
