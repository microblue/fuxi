# 第一集 分镜表：数据洪流

> 总时长 ~60s | 20 个镜头 | 4 场 + 结尾 | 1920×1080 横屏 24fps

---

## 场次 1-1 灵子文明首都·数据中枢 — 毁灭时刻

### S01 | 3s — 光之都市崩溃

| 项 | 内容 |
|---|------|
| 景别 | 大全景，摇臂下降 |
| 角色 | 无 |
| 画面 | 极致璀璨的未来都市。建筑由光构成，数据河流在空中流淌。突然所有光芒开始抽搐，城市响起刺耳警报。 |
| 运镜 | 平滑下降展现城市全貌，随后画面突然抽搐闪烁 |
| 情绪 | 惊叹 → 恐惧 |
| 音效 | 空灵环境音 → 刺耳警报，电子失真 |
| 备注 | **强钩子开场**：未来都市壮美与毁灭的强烈反差，3 秒内必须抓住观众 |
