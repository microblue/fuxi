# 第十七集：婚典阴谋

| 项目 | 内容 |
|------|------|
| 集数 | 17 |
| 时长 | ~60s |
| 场次 | 3 |
| 主要角色 | 伏羲、女娲、石昊、蚩尤、轩辕侍从、嫘祖 |
| 主要场景 | 全城、宴会广场 |

---

## 场次 17-1：婚礼筹备

**场景**：全城

**时间**：日

**人物**：伏羲、女娲、石昊、各氏族代表

（全城张灯结彩。各氏族送来贺礼:）

- 神农氏:九株发光奇草,布置成"同心园"。
- 轩辕氏(嫘祖代表):九匹极品丝绸,制成礼服。
- 其他小部落:⻝物、手工艺品、祝福图腾。

（伏羲和女娲试穿礼服。罕⻅地露出羞涩表情。）

**石昊**（打趣）："大人,成亲后,家务活谁做啊?用代码做吗?"

（众人哄笑。）

---

## 场次 17-2：婚宴下毒

**场景**：宴会现场

**时间**：夜

**人物**：众人、九黎间谍（伪装成轩辕侍从）、轩辕氏真正侍从、嫘祖

（宴会高潮,众人敬酒。九黎间谍(伪装成轩辕侍从)在酒坛中下入"代码病毒"——无色无味,喝下后三小时内会代码紊乱,重则死亡。）

（轩辕氏的真正侍从发现异常,但已有多人喝下。他急忙去找嫘祖。）

---

## 场次 17-3：婚宴变战场

**场景**：宴会广场

**时间**：夜

**人物**：轩辕侍从、伏羲、女娲、蚩尤、众人

**轩辕侍从**（冲进）："公主!酒里有毒!是九黎的人!"

（话音刚落,城外响起进攻号⻆!蚩尤军队趁机攻城!）

（城内,喝下毒酒的人开始痛苦倒地,身体代码乱窜。）

**伏羲**（扶住一个中毒的族⻓）："女娲!解毒!"

**女娲**（全力催动生命代码）："是病毒代码!我在解析......需要时间!"

（城内乱作一团:有人中毒,有人御敌,有人恐慌。）

**伏羲**（登上城墙,看到城外黑压压的机械军）："蚩尤......你选今天......"

**蚩尤**（城外狂笑）："双喜临⻔!我送你一份大礼——城破人亡!"

---

### 【本集终】

婚礼被毁,危机全面爆发。
