# 世界观设定 — 伏羲纪元

## 核心概念

世界的本质是"代码"。万物——树木、水流、生物、大地——皆由底层数据结构编译而成。掌握"原生代码"即可直接读写世界底层规则。

远古曾存在一个高度数据化的文明——**灵子文明**。灵子文明的代码者能通过意识直接操控世界代码，但被宇宙级清洗力量"**熵**"执行格式化，文明毁灭。灵子文明最后的代码者**羲和**在毁灭前夕启动"**火种协议**"——将文明核心数据转为生物编码，植入随机投放的新生载体，散向宇宙。其中一枚携带八卦图案的火种光点，降落在原始地球。

## 双时空结构

| 时空 | 描述 | 视觉基调 |
|------|------|----------|
| **前世：灵子文明** | 极致璀璨的未来都市，建筑由光构成，数据河流在空中流淌。高度数据化文明，人类可通过意识直接操控世界代码。在熵的格式化程序中毁灭。 | 流光建筑、数据河流、金色数据操控界面、通天光柱 |
| **今生：原始时代** | 文明重启，部落时代。沼泽、暴雨、原始森林、兽皮石器。残余代码碎片散落世界，等待被重新激活。 | 泥泞沼泽、暴雨闪电、兽皮粗麻、银蓝色光流坠落 |

## 力量体系

### 代码视觉（Code Sight）

左眼激活后可"看穿"万物底层数据结构。第一集中首次展现三种视觉层：

| 对象 | 代码视觉呈现 |
|------|-------------|
| 树木 | 绿色生长代码串 |
| 水面 | 分子结构网格 |
| 人体（自身手部） | 皮肤下的生物电流蓝线 |
| 熵的攻击数据流 | 黑色锯齿状结构，可"抓住"并扯断 |

### 代码操控（Code Manipulation）

直接修改物质的底层代码，改变物理状态。首次展现：伏羲将泥土代码重写为流沙，困住熵单位。

### 火种协议（Seed Protocol）

灵子文明的终极保险：将文明核心数据转为生物编码，植入新生载体。载体随机投放，存活率低于 0.03%，且无法保留记忆。伏羲体内携带的火种以半透明晶体形态降落，触碰后激活左眼代码视觉。

## 熵（Entropy）

宇宙级格式化力量。以"清除异常代码"为使命，执行星球级别的数据清洗。

- **执行单位**：熵单位 / 熵格式化单位（苍白几何体，正八面体）
- **攻击方式**：黑色数据流触手，可将生物像素化分解
- **决策层**：中央仲裁者（第一集结尾伏线："向中央仲裁者发送报告"）
- **核心逻辑**：检测异常代码残留 → 提取分析 → 威胁等级评估 → 格式化执行

## 对立结构

| 阵营 | 代表 | 核心行为 |
|------|------|----------|
| 原生代码（创造/改写） | 伏羲、女娲、灵子文明遗产 | 读写世界底层规则，保护与创造 |
| 熵（删除/格式化） | 熵单位、中央仲裁者 | 清除异常代码，执行宇宙秩序 |

**核心冲突**：自由意志 vs 系统规则，创造 vs 格式化，混沌中的生命 vs 绝对的秩序。

## 场景设定

### 场景 A：灵子文明首都 · 数据中枢

| 项目 | 描述 |
|------|------|
| **空间** | 极致璀璨的未来都市。建筑由纯光构成，半透明、流动、不断重构。数据河流在建筑之间的空中流淌，形成立体交通网络。城市中心矗立中枢塔，塔顶有控制台。 |
| **光线** | 全域自发光，建筑本身即光源。正常状态为温暖金白色；格式化警报触发后光芒开始抽搐、闪烁，色温骤降为冰冷的银蓝。 |
| **色调** | 金色 / 银蓝 / 白色为主，无自然色。格式化时加入红色警报闪烁。 |
| **关键道具** | 中枢塔顶控制台（全息投影交互界面）、通天光柱（火种协议发射装置）。 |
| **情绪** | 从极致华丽到末日毁灭。壮美与悲怆并存。 |
| **Prompt 关键词** | `breathtaking futuristic city built entirely of light, luminous architecture, rivers of data flowing through sky, holographic city, central tower, cosmic scale, glitching and stuttering light` |

### 场景 B：上古雷泽 · 沼泽地带

| 项目 | 描述 |
|------|------|
| **空间** | 原始蛮荒的大地。广阔的沼泽地带，积水没至脚踝到膝盖。散布枯木、芦苇、泥泞小径。远处有低矮山崖和原始森林边缘。 |
| **光线** | 暴雨夜。几乎无自然光源，仅靠闪电瞬间照亮。火种降临时银蓝色几何光流撕裂天空，形成短暂的非自然照明。 |
| **色调** | 深灰 / 墨绿 / 土褐。银蓝色光流坠落时形成冷暖色强对比。 |
| **关键道具** | 雷兽足迹（狩猎线索）、骨制长矛（猎人武器）。 |
| **情绪** | 原始、危险、神秘。暴雨的压迫感中突降异象。 |
| **Prompt 关键词** | `primitive swamp at stormy night, torrential rain, mud, dead trees, raw primal landscape, silver-blue geometric light tearing through sky, lightning illumination` |

### 场景 C：漩涡边缘（沼泽中央）

| 项目 | 描述 |
|------|------|
| **空间** | 沼泽中心的浅水区。火种光流坠入后形成发光漩涡，漩涡中心浮着一块拳头大小的半透明晶体。周围水面被银蓝色光芒照亮，形成宁静而诡异的光晕。 |
| **光线** | 漩涡自发光（银蓝色），由下而上照亮接近者的面部。晶体触碰瞬间爆发金色强光。 |
| **色调** | 银蓝色漩涡 + 暗金色觉醒光。黑暗沼泽背景中的孤立光源。 |
| **关键道具** | 半透明晶体（火种载体，内含灵子文明核心数据）。 |
| **情绪** | 催眠般的吸引力，接触瞬间转为剧烈痛苦与变革。 |
| **Prompt 关键词** | `glowing silver-blue vortex in swamp water, translucent crystal floating at center, hypnotic light, golden data streams erupting on contact, transformation moment` |

### 场景 D：熵单位降临（沼泽上空）

| 项目 | 描述 |
|------|------|
| **空间** | 同一片沼泽，但天空骤然暗下——超越正常暴风的不自然黑暗。三个苍白几何体从黑暗中无声降下，悬浮于沼泽上方约三米处，形成三角编队。 |
| **光线** | 极暗环境。几何体表面红色裂纹是唯一持续光源，脉动同步。格式化攻击时黑色数据流自身不发光，但被击中目标发出像素化白光。 |
| **色调** | 苍白 / 黑红 / 像素化白光。与之前银蓝色和金色形成鲜明对比。 |
| **关键道具** | 正八面体熵单位 ×3、黑色数据触手、像素化分解特效。 |
| **情绪** | 冰冷、机械、无情。非人类的威胁感。 |
| **Prompt 关键词** | `pale white octahedron entities descending silently from dark sky, red cracks pulsing, black data tendrils, pixelation dissolution effect, cold alien menace, mechanical precision` |
